# Data Dictionary

## Dataset Description

The dataset contains mathematics examination marks for 10 students. It is used to demonstrate basic descriptive statistical methods.

## Variables

| Variable | Data type | Description |
|---|---|---|
| Student | Text | Identifies each student using a unique label. |
| Marks | Integer | The student's examination mark, recorded on a scale of 0 to 100. |

## Dataset Details

- Number of observations: 10
- Number of variables: 2
- Missing values: None in the original dataset
- Data format: CSV

## Notes

The dataset is a small illustrative example created for this project. It does not represent actual student records or results from a real examination.
