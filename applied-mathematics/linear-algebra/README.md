# Linear Algebra

## Overview

This section examines vector spaces, matrices, linear transformations and systems of linear equations, including their applications in mathematical and computational problems.

## Topics

- Matrix operations
- Determinants and matrix inverses
- Systems of linear equations
- Gaussian elimination
- Vector spaces and subspaces
- Linear transformations
- Eigenvalues and eigenvectors
- Diagonalisation

## Applications

Linear algebra will be applied to economic input-output models, data analysis, systems modelling and computational mathematics.
